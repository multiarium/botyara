# Бот-перекуп для Termux

Мониторит Авито 24/7, оценивает маржу и риск каждого объявления
и присылает в Telegram карточки только реально выгодных лотов.

## Что умеет

- 🔍 Сканирует Авито по твоим фильтрам (сортировка по дате — свежие первыми)
- 📈 Считает рыночную цену по медиане похожих лотов (учитывает объём памяти)
- 💰 Считает чистую прибыль: рынок − торг − комиссия − покупка − доставка
- ⚠️ Риск-скоринг 0–10: подозрительно низкая цена, свежий аккаунт,
  стоп-слова в заголовке («на запчасти», «MDM», «утопленник», «реплика»...)
- 🔥 Присылает карточку с фото и кнопками «Беру / Мимо», ведёт статистику
- 🚨 Сам сообщает, если Авито начал блокировать парсер

## Установка на Termux

```bash
# 1. Скопируй папку flip_bot на телефон (например, в ~)
# 2. В Termux:
cd flip_bot
bash install.sh
```

## Настройка (2 минуты)

1. В Telegram открой **@BotFather** → `/newbot` → скопируй токен.
2. `nano config.yaml` → впиши токен в `telegram.token`.
3. Заодно проверь `location_id` (город) и фильтры под свои категории.
4. Запусти: `python bot.py`
5. Напиши своему боту `/start` — он запомнит твой chat_id и начнёт работу.

## Работа 24/7

1. Установи Termux:API и выдай разрешения; в Termux выполни `termux-wake-lock`.
2. В настройках Android отключи оптимизацию батареи для Termux.
3. Запускай через `bash run.sh` — он сам перезапустит бота при падении.
4. Автозапуск после перезагрузки телефона: установи приложение **Termux:Boot**
   и создай файл `~/.termux/boot/start-flipbot.sh`:

   ```bash
   #!/data/data/com.termux/files/usr/bin/sh
   termux-wake-lock
   cd ~/flip_bot && bash run.sh
   ```

## Настройка под себя

Всё в `config.yaml` — бот подхватывает изменения сам, перезапуск не нужен:

- `min_margin_percent` — порог маржи для уведомления (стартовые 25% — норм)
- `max_risk_score` — насколько рискованные лоты показывать
- `delivery_cost` — твоя средняя доставка
- `filters` — модели и потолки цен; добавляй/выключай свободно
- `check_interval_minutes` — не ставь меньше 5, Авито банит за частые запросы

## Важно знать

- Парсер использует неофициальный мобильный API Авито. Это нарушает их
  правила сервиса: теоретически возможны временные ограничения по IP
  (лечится паузой — бот сам предупредит). Ключ приложения лежит в
  `parsers/avito.py` — если Авито его сменит, бот напишет об ошибке,
  а свежий ключ ищется в open-source проектах на GitHub.
- Юла вынесена в `parsers/youla.py` как заглушка — её данные идут через
  закрытый GraphQL, подключим отдельным этапом.
- Бот — это фильтр и калькулятор, а не гарантия. Финальную проверку
  (фото, отзывы продавца, безопасная сделка) всегда делай глазами.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | привязать чат и начать |
| `/status` | состояние сканера и ошибки |
| `/filters` | список активных фильтров |
| `/stats` | статистика и потенциальная прибыль |
| `/test` | сканировать прямо сейчас |
| `/pause`, `/resume` | пауза / продолжить |
